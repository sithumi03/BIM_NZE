Phase 3
Handover Validation
The most critical stage. BIM verified against installed assets. FM team signs off only when data is complete, accurate, and usable. Research found BHU = 3.06 — the weakest link.
Phase 3 completion0%
Handover process steps
1
Site verification walk
FM team physically verifies each BIM asset against installed equipment. Discrepancies logged and resolved before sign-off.
2
Data completeness audit
All critical fields checked — no null values, no placeholder data. Asset IDs confirmed consistent in BIM, BMS, and CMMS.
3
BMS integration test
Live BMS alarms verified to link to correct BIM asset records. Energy metering tested against sub-meter zones.
4
FM sign-off
FM team lead formally accepts BIM handover as performance contract. Not just document delivery — data must be operationally usable.
Handover checklist
Site verification completed — BIM matches installed assets
Data completeness audit passed (zero critical nulls)
BMS–BIM live integration tested and confirmed
FM team trained on BIM data access and update procedures
FM lead formal sign-off on performance contract
